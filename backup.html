Quick Guides

📱 Recording Scans

Use Home to add Ryobi and AEG scans, then save the day. Existing days can be edited from Calendar.

📅 Using the Calendar

Tap any date to edit scan records, Store visits, Events, excluded days or custom workdays.

🏪 Store Tracking

Assign scans to Stores so Top Stores, averages and visit history stay accurate.

🎪 Event Tracking

Add an Event from Calendar. Events can span dates and Stores, and can be excluded from the QR KPI per day.

📊 Stats & Historical Quarters

Use the arrows at the top of Stats to browse quarters with saved records. Store, Event and Personal Best stats follow the selected quarter.

🎯 KPI Tracking

The Quarterly KPI Tracker on More shows your four KPIs. QR scans can exclude specific Event days.

🏪 Multi-Store Days

Use Add Another Store in a Calendar day and record Ryobi/AEG scans separately for each Store.

💾 Backup & Restore

Export a JSON backup regularly. Import replaces the current tracker data with the selected backup.

What’s New in Version 10.9.2.1
  • Added quarter-scoped Daily Challenge history and completion statistics.
  • Added Store ranking by average scans per visit.
  • Added Event-day vs normal-workday performance comparison.
  • Added historical completed-quarter summary cards.
  • Monthly goals now prorate by effective workdays inside each individual month.
  • Projected finish now uses effective workdays and does not treat an untouched morning as a zero-scan workday.
  • Required pace uses remaining effective workdays and shows a quarter shortfall when no workdays remain.
  • Daily Challenge mini-games now animate and reveal their result in a dedicated popup.
  • Played challenge cards now focus only on today’s target and progress.
  • Closing the Daily Briefing now performs a fresh-day Home refresh so yesterday’s challenge cannot remain visible.
  • Made the app title and Lifetime Level banner substantially thinner and removed the Today x/y count from the Level banner.
  • Fixed More-page mobile sizing, aligned Calendar weekday/day columns and pinned the primary navigation to the visible bottom safe area.
  • Improved Matrix Mode readability across light statistic blocks, Today’s Scans, Achievements and the QR notice card.
  • Refined Gamer Mode’s Today’s Scans controls with rounded light panels, dark text and higher-contrast +/- buttons.
  • Improved Gamer Mode contrast on Achievement cards and the QR backup notice card.
  • Improved text contrast inside Gamer Mode’s light statistic and counter blocks.
  • Improved Gamer Mode contrast with darker cards, brighter text, clearer controls and a subtler arcade background.
  • Daily Challenge now remains on Home for the full day and refreshes its progress after saved or edited scans. It only changes when the calendar date changes.
  • Achievement notifications triggered by starting a Daily Challenge are held for one minute so the game result has time to land first.
  • Daily Challenge now clearly states “No challenge today” on non-workdays while retaining the optional challenge button.
  • Daily Briefing appears once per new day with yesterday’s results, quarter average and today’s required pace.
  • Daily Challenges add Dice, Cards, Wheel and Mystery Box mini-games with personalised targets based on recent performance and quarter pace.
  • Added six Daily Challenge achievements plus Gamer and Matrix theme rewards.
  • Unsaved-scan recovery remains mandatory and is resolved before the Daily Briefing.
  • Added live lifetime-scan progress to Blaze It, Mythical and The Institution.
  • Fixed achievement progress display using the exact achievement names and thresholds from the live catalogue, with explicit progress text/bar styling.
  • Achievement cards now render live progress for measurable locked achievements, including lifetime scan and active-streak milestones.
  • Backup actions now use Download and Copy only. Successful downloads and copies immediately update Last Backup.
  • KPI completion state is now consistent between the expanded and collapsed tracker, and the collapsed summary refreshes immediately after KPI changes.
  • Fixed the collapsed Quarterly KPI summary to use the live KPI actual/target fields and show In Progress and Completed counts.
  • Hardened Settings startup so the modal opens first and remains usable even if a summary widget fails.
  • Fixed Settings not opening after the Work Calendar redesign.
  • Fixed Next Workday Target and previous-quarter refresh.
  • Improved backup metadata cleanup/status and added Active Day Rate.
  • Settings pages now include Profile unlocks, live Goals, Work Calendar lists, Help guides, Data Health and Tracker history.
  • More cards now show useful collapsed KPI and backup summaries.
  • Stats adds previous-quarter comparisons, Store visit history, Event occurrences and achievement progress.
  • Home now shows a next-workday target and the browser title no longer includes a version number.
  • Experience menu now explains Simple and Complete modes, with a disabled Secret Mode placeholder for future use.
  • Expanded Quarterly Progress now uses a daily Ryobi/AEG stacked bar chart with tappable day details.
  • Personal Bests This Quarter now uses a three-column layout.
  • Home ahead/behind values are limited to one decimal place.
  • Appearance redesigned with standard modes and scalable unlockable-theme tiles.
  • Settings modal is now centred, height-limited and internally scrollable on phones.
  • Fixed startup compatibility for the optional Store Tracking announcement.
  • Settings redesigned into focused sub-pages.
  • Personal Bests split into This Quarter and All Time.
  • New Event and multi-store achievements with redundant achievements removed.
  • KPI Tracker and Backup cards are collapsible.
  • Quarterly Progress chart now opens a detailed view.
